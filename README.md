# RateHarbor（预览版）

一个为独立酒店和小型酒店集团做远程收益管理与 OTA 管理的 B2B 服务网站，用 Astro 构建的静态站点。

- 在线预览：https://kkoryz.github.io/hotel-rm/
- 预览页面带 `noindex`，robots.txt 禁止抓取，不会被搜索引擎收录。

## 现状

这是设计预览版，还不是正式上线版本：

- 这一版已通过两项版式审计和整页设计评审（19 页中 11 页逐页评审，其余 8 页同类页只做了审计）；
- 联系方式（hello@rateharbor.com、+1 (416) 555-0187、多伦多地址、营业时间）是占位内容，上线前换成真实信息；
- 公司事实（团队人数、服务范围、所在地等）是临时内容，上线前由业主确认或替换；
- 信任条、客户名单、案例和客户评价都是占位，不是真实客户；
- 所有照片都是为本站生成的图片，没有使用其他网站的图片。

## 本地运行

```bash
pnpm install
pnpm dev
```

`gh-pages` 分支是构建好的静态页面，供 GitHub Pages 使用。
